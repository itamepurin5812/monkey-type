無限の猿定理ゲーム

遊び方：index.html をブラウザで開きます。インターネット接続は不要です。
最初の画面で難易度を選び、スペースキーで開始します。
ホーム：index.html / 各ゲーム：easy.html、normal.html、hard.html
難易度選択で専用のHTMLページへ移動します。各ページのホームリンクで戻れます。
終了後もスペースキーで再挑戦できます。「難易度を選び直す」で選択画面に戻ります。
ページは画面の高さに合わせ、縦スクロールをしないレイアウトです。
PCの物理キーボード向け。日本語入力をオフにし、表示どおりのローマ字を入力します。
shi/si、chi/ti、tsu/tu、fu/hu、ji/zi、sha/sya、cha/tya/cyaなどの別綴りに対応。
促音（sshi/ssi、cchi/tti、ltu/xtuなど）と、ん（n/nn/xn）にも対応。
stories.jsには標準の綴りを1つ書けば、対応する別綴りも自動で受け付けます。
得点は実際に正しく入力したキー1打につき10点です。
長押しはカウントせず、一打ずつ判定します。英字以外は判定対象外です。
得点は正解1文字につき10点。制限時間はありません。

easy：文章を全表示。ミスで減点なし。
normal：共通一覧の文章を推測して入力。ミスのペナルティなし。正解したキーだけ進みます。
hardと同じく、一番最初のローマ字1文字は入力済みのヒントとして表示します。
2文字目以降は見えず、推測で正しく打てた文字だけが現れます。
例：m が表示されていたら u を打つと mu になります。次の k は表示されません。
最初のヒント1文字には得点が付きません。
先の日本語は隠し、まとまりを打ち終えるごとに表示します。
hard：easyと同じ文章一覧。最初のローマ字1文字は入力済み。
2文字目から見えない続きを推測して入力し、正解した文字が現れます。
読み終えたまとまりの日本語も現れます。
英字のミス1回で終了。文章全体の答えは終了時にも表示しません。

題材は伝承の昔話「桃太郎」。現代の本からの転載ではなく、このゲーム用に整えた短文です。
文章とローマ字の編集：stories.js を変更します。
standard：EASY・NORMAL・HELLすべてで共通に使う文章一覧。ここへ文章を追加します。
物語はスペースキーで開始するまで表示しません。開始・再挑戦時に出題します。
同じページ内では直前の文章を避けます（一覧が1件のときは同じ文章）。
クリアすると紙吹雪・物語タイトル・タイムを表示します。点数表示はEASYのみです。
スペースキーまたは結果画面のボタンで次の文章へ進めます。

追加例：一覧の [ と ] の間に、次の形で1件追加します。
{ title: '自分の文章のタイトル', parts: [
  ['こんにちは', 'konnichiha'],
  ['せかい', 'sekai']
] },

ローマ字は半角小文字のa〜zだけで書き、空白・記号は入れません。
日本語はまとまりごとに区切ります。画面では区切りに「、」を付けます。
hardではまとまりを打ち終えると、その部分の日本語が現れます。
文章の対象年齢・50字以内という制限はありません。
画面に収めるため、他モードもまずは現在のサンプル程度の長さにしてください。
記事や書籍などの文章を追加する場合は、利用可能なものを選んでください。

GitHub Pagesで共有する場合：
1. GitHubで公開リポジトリを作成。
2. index.html、easy.html、normal.html、hard.html、style.css、stories.js、romaji.js、game.jsをリポジトリ直下にアップロード。
3. Settings > Pages > Deploy from a branchでmain / (root)を指定。
4. 発行されたURLを展示用PCで開く。
